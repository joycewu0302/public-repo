## 反思

我在這一站根據自己前面設計的世界觀中的各種威脅，設計了一隻存活在這個世界的生物。在這一站中讓我卡最久的地方是關於生物行走的姿勢，我的生物有點參照著蜥蜴在設計，因此設定上一般情況下是在地面上爬行，但AI生出來的模型行走姿勢卻不是我想要的樣子。一直嘗試用文字敘述幫他拆解動作讓他聽懂，但好像越用越糟糕。最後請他參考了我前一次做的試作檔裡面模型的姿勢才好不容易讓他有點接近我想要的爬行樣子，但還是有些不自然，因此在下一站我像要優先修改這個問題，此外，在設定上這種生物具有些微的公母差異，因此希望下次也能連帶請AI將生物的公母差異做出來。
（一百到兩百字，自己寫，AI 不代寫：你這一站做了什麼、卡在哪、怎麼解的、下一站想改什麼。）

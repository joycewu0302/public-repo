在這一站中，我在終端機用AI幫我在github上面建立repo，並照著老師的issue上的指示建立資料夾，以及跟AI一起構想期末專案需要的世界觀。一開始在請AI幫我建完資料夾後卻發現在我的github上面並沒有看到建立的七個資料夾，後來我再去問了我的gemini發現我的指令裡面沒有叫agy幫我把建好的資料夾commit跟push上去，之後我再請agy幫我執行這個動作後就成功看到資料夾了。而關於下一站想改什麼，我想要稍微改動之前原先訂好的世界觀設計，除了把它修得更完善之外，我也想再加入更多科幻的要素在裡頭。

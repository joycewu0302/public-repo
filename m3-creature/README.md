## 反思
在這一站中，我前前後後修改了許多設定，像是原先設定育兒袋要在腹部，但後來在請AI幫我做模型時才發現如果生物的移動方式是貼地爬行，那育兒袋有裝寶寶的情況下就會影響生物移動，因此將他改到背部。還有，在泡澡動作上我也修改了很久，原先是想讓生物像是人那樣坐在水池邊泡澡，但請AI幫我做出來後又感覺怪怪的，但仰漂在水上又會讓生物頭上的裝置進水，而且這樣寶寶也會溺死。所以後來就改成像是四肢打開腹部泡水的姿勢。接下來在下一站，我希望能夠先將生物育兒袋中的寶寶數量提升到三隻，並開始出現複數隻生物，並讓他們之間能夠交流、競爭等，衍伸出族群行為，慢慢完善自己的設計。
（一百到兩百字，自己寫，AI 不代寫：你這一站做了什麼、卡在哪、怎麼解的、下一站想改什麼。）

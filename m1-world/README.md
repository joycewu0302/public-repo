## 反思
在這一站中，我完善整個世界觀的設定，並為我的物種做了初步設計，這一站中最卡的地方是資料考據，雖然已經對環境如何改變有具體的想法了，但在某些設定上一直找不到相關的資料去佐證設定的合理性，關於這個部分，我先網路查找相關資訊與案例，從新聞稿中提供的參考資料在近一步挖到資料發布的單位並考據資料的正確性並佐證。下一站要開始做生物了，雖然現在已經有初步的想法，但我想我可能還會再新增或修改部分設定。
（一百到兩百字，自己寫，AI 不代寫：你這一站做了什麼、卡在哪、怎麼解的、下一站想改什麼。）
